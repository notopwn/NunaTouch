# NunaTouch

사진 위를 쓰다듬는 동작을 실험하는 정적 웹 프로토타입입니다.

`index.html`을 브라우저로 열고 대상 사진을 선택한 뒤 **반응 영역 지정**을 눌러 테두리를 클릭합니다. 세 점 이상 지정한 후 **영역 완료**를 누르고 사진 위를 드래그합니다. 필요하면 별도 손 사진을 불러와 윤곽을 직접 지정할 수 있습니다. 사진은 브라우저에서 처리합니다.

기본 손 이미지는 제공된 사진을 바탕으로 AI가 배경을 제거하고 일부를 재구성한 것입니다. 대상 분리와 마스크 지정은 수동이며, 가려진 배경 복원은 지원하지 않습니다. 원본 사진은 저장소에 포함하지 않습니다.

개발 계획은 [PLAN.md](PLAN.md)를 참고하세요.
